## 1. EXECUTIVE OVERVIEW

Dokumen ini membedah analisis dampak arsitektur (*Architecture Impact Analysis*) untuk implementasi **5 Epic Utama V1.1** sebelum tahap penulisan kode (*coding*) dimulai. 

Tujuan utama analisis ini adalah memastikan **Zero-Regression pada V1.0**, migrasi database non-destruktif, isolasi keamanan hak akses (RBAC), dan pemeliharaan performa sistem.

---

## 2. IMPACT MATRIX PER SYSTEM LAYER

| Komponen Sistem | Tingkat Dampak | Ringkasan Perubahan | Mitigasi Risiko Regresi |
| :--- | :---: | :--- | :--- |
| **Database Schema** | **Medium** | Penambahan 3 tabel baru (`skill_matrix`, `certificates`, `practical_evaluations`) dan relasi foreign key aditif. | Migrasi bersifat murni *additive* (tanpa `DROP TABLE` / `ALTER DROP COLUMN`). Semua data riwayat V1.0 tetap utuh. |
| **Backend REST API** | **Low-Medium** | Penambahan controller & service baru (`CompetencyModule`, `CertificatesModule`, `EvaluationModule`, `AssistantModule`). | Endpoint V1.0 tetap mempertahankan kontrak request/response lama tanpa breaking changes. |
| **Authentication & RBAC** | **Low** | Penambahan hak akses baru untuk Trainer (input evaluasi praktikum) dan verifikasi publik untuk QR sertifikat. | Endpoint sertifikat publik menggunakan rate limiter ketat (10 req/menit per IP) untuk mencegah scraping. |
| **Background Worker** | **Medium** | Penambahan antrian (*queue job*) untuk rendering PDF sertifikat dan proses ekstraksi semantik RAG SOP. | Worker dieksekusi secara asynchronous di background terpisah agar tidak membebani latensi REST API. |
| **Frontend Web App** | **Medium** | Penambahan halaman baru: Tab Skill Matrix di profil, halaman verifikasi sertifikat publik (`/verify/:id`), dan dialog Chat AI. | Menggunakan arsitektur modular Next.js App Router dengan lazy loading pada komponen chart. |
| **Storage & Object Store** | **Low** | Penyimpanan file PDF sertifikat digital yang diterbitkan. | Menggunakan direktori terisolasi `storage/certificates/` dengan format penamaan berbasis UUID. |

## 3. DATABASE MIGRATION STRATEGY (NON-DESTRUCTIVE)

```sql
-- =========================================================================
-- MIGRATION V1.1: ADDITIVE EXTENSIONS (ZERO DATA LOSS GUARANTEE)
-- =========================================================================

-- 1. Tabel Matriks Kompetensi Karyawan
CREATE TABLE IF NOT EXISTS skill_matrix (
  id VARCHAR(64) PRIMARY KEY,
  user_id VARCHAR(64) NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  brand_id VARCHAR(64) NOT NULL REFERENCES brands(id) ON DELETE CASCADE,
  category VARCHAR(64) NOT NULL, -- 'HARDWARE', 'SOFTWARE', 'SOP', 'TROUBLESHOOTING'
  score NUMERIC(5,2) NOT NULL DEFAULT 0.00,
  level VARCHAR(32) NOT NULL DEFAULT 'BEGINNER',
  last_calculated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  CONSTRAINT uq_user_brand_category UNIQUE (user_id, brand_id, category)
);
CREATE INDEX IF NOT EXISTS idx_skill_matrix_user ON skill_matrix(user_id);
CREATE INDEX IF NOT EXISTS idx_skill_matrix_brand ON skill_matrix(brand_id);

-- 2. Tabel Sertifikat Resmi Digital
CREATE TABLE IF NOT EXISTS certificates (
  id VARCHAR(64) PRIMARY KEY,
  certificate_number VARCHAR(128) UNIQUE NOT NULL,
  user_id VARCHAR(64) NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  program_id VARCHAR(64) NOT NULL REFERENCES training_programs(id) ON DELETE CASCADE,
  brand_id VARCHAR(64) NOT NULL REFERENCES brands(id) ON DELETE CASCADE,
  final_score NUMERIC(5,2) NOT NULL,
  issued_at TIMESTAMP WITH TIME ZONE DEFAULT NOW(),
  verification_token VARCHAR(256) UNIQUE NOT NULL,
  pdf_url TEXT,
  status VARCHAR(32) DEFAULT 'ACTIVE'
);
CREATE INDEX IF NOT EXISTS idx_certificates_user ON certificates(user_id);
CREATE INDEX IF NOT EXISTS idx_certificates_token ON certificates(verification_token);

-- 3. Tabel Evaluasi Praktik Trainer
CREATE TABLE IF NOT EXISTS practical_evaluations (
  id VARCHAR(64) PRIMARY KEY,
  user_id VARCHAR(64) NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  trainer_id VARCHAR(64) NOT NULL REFERENCES users(id) ON DELETE CASCADE,
  course_id VARCHAR(64) NOT NULL REFERENCES courses(id) ON DELETE CASCADE,
  esd_score NUMERIC(5,2) NOT NULL DEFAULT 0.00,
  disassembly_score NUMERIC(5,2) NOT NULL DEFAULT 0.00,
  diagnosis_score NUMERIC(5,2) NOT NULL DEFAULT 0.00,
  documentation_score NUMERIC(5,2) NOT NULL DEFAULT 0.00,
  total_score NUMERIC(5,2) NOT NULL DEFAULT 0.00,
  trainer_notes TEXT,
  evaluated_at TIMESTAMP WITH TIME ZONE DEFAULT NOW()
);
CREATE INDEX IF NOT EXISTS idx_practical_evaluations_user ON practical_evaluations(user_id);
CREATE INDEX IF NOT EXISTS idx_practical_evaluations_course ON practical_evaluations(course_id);
```

## 4. SECURITY & DATA PRIVACY IMPACT

1. **Evaluasi Praktik Meja Kerja:** Hanya akun ber-role `TRAINER` dan `SUPER_ADMIN` yang diizinkan menginput dan mengubah nilai praktikum (`RolesGuard: TRAINER, SUPER_ADMIN`).
2. **Isolasi Lingkup Cabang Supervisor:** Supervisor hanya dapat melihat nilai matriks keahlian dan sertifikat milik teknisi di cabang mereka (`branchId` isolation).
3. **AI Knowledge Assistant Guardrails:**
   - Asisten AI dibatasi aksesnya hanya pada dokumen SOP dan modul pelatihan resmi milik brand yang diizinkan untuk teknisi bersangkutan.
   - Proteksi *Prompt Injection*: Input teknisi disaring sebelum dikirim ke engine retrieval untuk mencegah ekstraksi data sensitif di luar dokumen materi.
4. **Verifikasi Publik Sertifikat:**
   - Endpoint `/api/v1/certificates/verify/:token` hanya mengembalikan metadata publik yang aman: *Nama Karyawan (disamarkan sebagian jika perlu), NIK, Nama Program, Tanggal Terbit, dan Status Keabsahan*. Tidak mengekspos kata sandi, email pribadi, atau nomor telepon.

## 5. PERFORMANCE & RESOURCE ESTIMATE

- **Latensi Query Analytics:** Agregasi skor matriks kompetensi di-cache menggunakan interval pembaruan terkelola saat penyelesaian ujian/praktik baru, sehingga tidak memicu kalkulasi ulang *full-table scan* di setiap pembukaan dashboard.
- **Kapasitas PDF Generation:** Background worker memproses penerbitan PDF secara serial di antrian pesan (*asynchronous queue*), membatasi beban memori maksimal 256MB.
- **AI RAG Latency:** Pencarian konteks SOP menggunakan pencarian semantik terindeks dengan target waktu respons $< 1.5$ detik.
