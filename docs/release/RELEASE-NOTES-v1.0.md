# Release notes — Version 1.0 (draft)

UNICOM UNIVERSITY Version 1.0 delivers secure session authentication and RBAC, Brand-scoped
training administration, participant/trainer provisioning, curriculum versioning, private
learning materials with server-derived completion, deterministic exams and progress, optional
AI-assisted Draft question authoring, scoped reporting/XLSX export, transactional notification
and account recovery, private certificates, responsive enterprise UI, and production-hardening
runbooks.

Deferred from Version 1.0: SSO, MFA, public/QR certificate verification, AI scoring/tutoring,
essay grading, gamification, advanced notification preferences, branch hierarchy, and a data
warehouse. AI remains optional/configurable. Three moderate transitive dependency advisories
are documented; no high or critical advisory is accepted.

This is a draft only. It must not be published until the GO-LIVE decision is changed to GO.
